☀️ 明亮風格：夕陽沙灘（Sunset Beach）
設計概念： 想像站在黃昏的沙灘上，天空是透亮的莫蘭迪青綠，陽光將沙灘染成溫暖的奶油金黃色。海水呈現透明的淺藍青，遠山輪廓化為深邃的灰青墨色。整體氛圍溫暖、明亮，帶有濃厚的熱帶海灘氣息。

- Primary (主色調 - 天空青 / 莫蘭迪青綠): #56C6CC (透亮的青綠色，宛如晴空下的淺海，清爽不刺眼)
- Secondary (次色調 - 海水 / 透明青): #7FCBD0 (比主色淡一階的透明青，適合次要按鈕或標籤底色)
- Accent (點綴色 - 金黃 / 主題金): #FFB97A (夕陽橘金色，用來點綴重要 Icon 或高亮元素)
- Background (主要背景色): #FCE6B8 (沙灘奶油色，溫暖的米白底調，取代生硬的純白)
- Menu / Drawer (選單底色): #FAD9A8 (暖沙色，比背景稍深，讓側邊欄有自然的陰影區隔感)
- Text (主要文字): #3A4A52 (灰青墨色，就像遠山的輪廓，閱讀起來比純黑更舒適)
- Highlight / Hero (高亮/首圖): #FFE9A8 (太陽高亮米，用於 Hero Banner 等需要柔和光感的區域)

🌙 暗色風格：暮色沙灘（Twilight Beach）
設計概念： 夕陽西沉後的沙灘，天空由深邃的靛藍紫漸層鋪開，遠方山影化為近乎純黑的暗色。月光柔和地灑落，玫瑰粉與珊瑚橘點綴著夜晚的溫度，整體充滿神秘而浪漫的暮色氣息。

- Primary (暗色主色 - 紫羅蘭 / 強調): #6A3A78 (深沉的紫羅蘭色，在暗色背景下作為主要互動色，神秘而不俗)
- Secondary (暗色次色 - 玫瑰粉 / 強調 2): #C26A86 (溫暖的玫瑰粉，用於次要互動或未激活狀態)
- Accent (暗色點綴 - 珊瑚 / 高光): #F2B788 (珊瑚橘，像沙灘上殘餘的夕陽餘溫，溫暖而明亮)
- Dark Background (Quasar $dark 背景): #0B1844 (深夜藍，極深的靛藍色，深邃但充滿層次)
- Dark Surface (卡片底色): #2A1F5C (靛紫色，微微透出光線的深紫礁石色，用於凸顯行程卡片)
- Menu / Drawer (選單底色): #0A0B22 (山影陰影，比主背景更深邃，讓拉出的選單有沉穩的包覆感)
- Text (暗色文字): #F2D5A8 (月光米色，柔和的暖白色，降低對比度以保護眼睛)
